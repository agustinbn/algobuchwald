# Árboles Binarios

---

## Árboles

- Un **árbol** es una estructura enlazada con más de "un siguiente" (los llamamos **hijos**).
- Un **árbol binario** (AB) es un árbol donde cada nodo puede tener **hasta dos hijos**: izquierdo y derecho.

### Definiciones
- **Raíz**: el padre de todo el árbol. A su vez, el hijo izquierdo es la raíz del sub-árbol izquierdo (idem derecho).
- **Hoja**: nodo sin hijos.
- **Nodo interno**: nodo con al menos un hijo.
- Pregunta planteada: ¿cómo hacemos las búsquedas en un AB? (sin ningún orden entre los nodos, hay que recorrer).

```go
type arbol[T any] struct {
    izq  *arbol[T]
    der  *arbol[T]
    dato T
}
```

## Ejercicio: altura de un AB

```go
func (ab arbol[T]) Altura() int {
    ... ?
}
```

- Es una función recursiva sobre los subárboles izquierdo y derecho.
- **Complejidad:** se visita cada nodo una vez → `T(n) = 2 T(n/2) + O(1)`. Por **Teorema Maestro** da **O(n)**.

## Recorridos en un AB

Hay 4 formas de recorrer un AB:
- **Pre order**: nodo, izquierdo, derecho.
- **In order**: izquierdo, nodo, derecho.
- **Post order**: izquierdo, derecho, nodo.
- **Por niveles**: nivel a nivel, usando una **cola**.

### Pre order
```
def preorder(ab, funcion):
    if ab == nil:
        return
    funcion(ab->dato)
    preorder(ab->izq, funcion)
    preorder(ab->der, funcion)
```

### In order
```
def inorder(ab, funcion):
    if ab == nil:
        return
    inorder(ab->izq, funcion)
    funcion(ab->dato)
    inorder(ab->der, funcion)
```

### Post order
```
def postorder(ab, funcion):
    if ab == nil:
        return
    postorder(ab->izq, funcion)
    postorder(ab->der, funcion)
    funcion(ab->dato)
```

### Por niveles
```
def niveles(ab, funcion):
    if ab == nil:
        return
    Q = cola()
    Q.encolar(ab)
    while not Q.esta_vacia():
        nodo = Q.desencolar()
        funcion(nodo->dato)
        if nodo->izq != nil: Q.encolar(nodo->izq)
        if nodo->der != nil: Q.encolar(nodo->der)
```

### Pre order en Go
```go
func (ab *Arbol[T]) preorder(funcion func(T)) {
    if ab == nil {
        return
    }
    funcion(ab.dato)
    ab.izq.preorder(funcion)
    ab.der.preorder(funcion)
}
```

- Se puede llamar a un método sobre un puntero `nil` en Go, por eso el caso base es `ab == nil`.

### Reconstruir un AB a partir de sus recorridos
Determinar cómo es el árbol cuyo **pre order** es `EURMAONDVSZT` y cuyo **in order** es `MRAUOZSVDNET`, e indicar su recorrido **post order**.

- El primer elemento del pre order es la **raíz** (`E`). Ubicándola en el in order, lo de la izquierda es el subárbol izquierdo y lo de la derecha el derecho (`T`). Se repite recursivamente.
- Estructura resultante: `E` tiene hijo izquierdo `U` y derecho `T`. `U` tiene izquierdo `R` (con hijos `M` y `A`) y derecho `O`. `O` sólo tiene hijo derecho `N`, que tiene sólo hijo izquierdo `D`, que tiene sólo hijo izquierdo `V`, que tiene sólo hijo izquierdo `S`, que tiene sólo hijo izquierdo `Z`.
- **Post order:** `MARZSVDNOUTE`
