# Estructuras en Go (y errores, strings, archivos)

---

## Structs

- Una `struct` empaqueta variables de distinto tipo en un tipo nuevo. Cada variable es un "miembro", accesible con `.`.
- Se puede tener valor o puntero. `&Punto{}` equivale a `new(Punto)`.

```go
type Punto struct {
    X int
    Y int
}

p := Punto{X: 1, Y: 3}
p2 := &Punto{X: 1, Y: 3}
```

- **Paso por valor vs referencia**: si una función recibe la struct por valor, modificarla adentro no afecta al original. Si recibe puntero, sí lo modifica.

```go
func modificarPunto(p *Punto) {
    p.Y = 5
}

p := Punto{X: 3}
modificarPunto(&p)
fmt.Println(p) // {3, 5}
```

## Métodos

- Un método se define con un **receiver**: indica a qué tipo pertenece.
- Receiver por valor: opera sobre una copia, no modifica el original.
- Receiver por puntero: sí modifica el original.

```go
func (p Punto) DistanciaAlOrigen() float64 {
    return math.Sqrt(float64(p.X*p.X + p.Y*p.Y))
}

func (p *Punto) SetX(x int) {
    p.X = x
}
```

## Anidación de structs

- Se pueden anidar y referenciar otras structs.
- Una struct puede referenciarse a sí misma sólo mediante **puntero**; de forma directa da error de tipo recursivo inválido (loop infinito de memoria).

```go
type Persona struct {
    direccion Direccion
    nombre    string
    padre, madre *Persona // no puede ser Persona a secas
}
```

- **Campo embebido** (sin nombre): se accede directamente a sus campos, y Go crea automáticamente un campo con el nombre del tipo.

```go
type Persona struct {
    Direccion // embebido, sin nombre
    nombre string
}

angie.calle       // acceso directo al campo embebido
angie.Direccion   // campo creado automáticamente por Go
```

- Si el struct padre tiene un campo con el mismo nombre que uno del embebido, el del padre "pisa" al embebido.
- Método `String() string`: si existe, se usa automáticamente al imprimir (`fmt.Println`) en vez de la representación default.

## Errores

- Tipo especial `error`, indica que algo falló en una sección de código. Su valor default es `nil`.
- Convención: la función retorna `(resultado, error)`; se chequea `if err != nil`.

```go
func Index(slice []int, e int) (int, error) {
    for indice, valor := range slice {
        if valor == e {
            return indice, nil
        }
    }
    return 0, errors.New("no se encontró el elemento")
}
```

- Para interpolar strings al crear el error: `fmt.Errorf("no se pudo conectar a la IP %v", ip)`.

## Strings

- Un string es un slice de `bytes` de sólo lectura (inmutable).
- Cada "caracter" es un `rune`, que puede ocupar entre 1 y 4 bytes (encoding siempre UTF-8).
- Iterar con `range` recorre **runas** completas; indexar con `[]` accede a **bytes** individuales, no runas.

```go
for i, c := range cadena {
    fmt.Printf("Posición %d: %c\n", i, c)
}

runes := []rune(cadena) // para indexar por caracter, no por byte
```

- Paquete `strings`: `strings.HasPrefix(...)`, `strings.Index(...)`, `strings.Replace(...)`.

## Archivos e input

- Leer de stdin, línea por línea:

```go
s := bufio.NewScanner(os.Stdin)
for s.Scan() {
    fmt.Printf("Leí: %s\n", s.Text())
}
if err := s.Err(); err != nil {
    fmt.Println(err)
}
```

- Leer de un archivo (mismo patrón de `Scanner` que con stdin):

```go
archivo, err := os.Open(ruta)
if err != nil {
    fmt.Printf("Error %v al abrir el archivo %s", ruta, err)
    return
}
defer archivo.Close()

s := bufio.NewScanner(archivo)
```

- Escribir a un archivo:

```go
file, err := os.Create(ruta)
if err != nil {
    fmt.Printf("No se pudo crear el archivo %s", ruta)
    return
}
defer file.Close()

datawriter := bufio.NewWriter(file)
datawriter.WriteString(dato + "\n")
datawriter.Flush() // asegura que se escriba todo
```
